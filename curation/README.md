# Curadoria

## Política temporária

Até que o catálogo seja criado na Fase 2, toda candidatura é bloqueada por padrão. Somente uma decisão explícita `publicar` ou `adaptar` poderá permitir a entrada de conteúdo em `docs/`.

A reutilização de texto exige autorização registrada. Cada asset deve ser recriado ou receber aprovação separada antes de qualquer uso.

Consultas ao Whazing ou a seu fork ocorrem somente em um workspace temporário separado. Esta pasta não é conteúdo do GitBook.
